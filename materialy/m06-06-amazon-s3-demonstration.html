Amazon S3 Demonstration

In this lesson, you will learn how to do the following:

  • Navigate in the AWS Management Console.
  • Create and configure an Amazon S3 bucket.
  • Upload individual files and complete folders to Amazon S3.
  • Configure both system-defined and user-defined object metadata.

This demonstration offers a hands-on exploration of the fundamental features of Amazon S3 through the AWS Management Console. You will be guided through the process of creating storage buckets, uploading files and folders, and configuring essential settings for both buckets and objects. Whether you're storing application data, website files, or backup archives, this demonstration will show you how to get started with the core functionality of Amazon S3.
