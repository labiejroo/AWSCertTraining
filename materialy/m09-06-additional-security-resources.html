Additional Security Resources

In this lesson, you will learn how to do the following:

  • Identify sources of AWS security documentation.
  • Identify security resources available on the AWS Marketplace.

AWS security documentation

There are lots of considerations when dealing with security on AWS. Make sure you read the documentation on securing your AWS resources because it varies from service to service.

  • For general information on AWS security, identity, and compliance services, refer to Security, Identity, and Compliance on AWS.
  • To find answers to questions, troubleshoot issues, and learn more about AWS security services, refer to the Knowledge Center.
  • To search through documentation by product category, refer to AWS Security Documentation.
  • For expert insights, best practices, and updates on security-related features, refer to the AWS Security Blog.

AWS Marketplace security resources

The AWS Marketplace provides a digital catalog where you can purchase third-party software and services that run on AWS. This includes the following types of security services.

Threat detection and prevention toolsIdentify and block malicious activities.

Identity and access management toolsControl user permissions and authentication.

Data protection toolsEncrypt and safeguard sensitive information.

Compliance and governance toolsMeet security regulatory requirements.

To explore security solutions offered through the AWS Marketplace, refer to Cloud Security Software.
