Specialized use cases architecture diagrams

Delivering customer solutions by combining specialized AWS services

Let's review the solutions discussed in the video. The following architecture diagrams demonstrate how you can combine AWS services together in different ways to solve for specific business problems.

Serverless web backend monitored by X-Ray

This is a typical serverless web backend with X-Ray monitoring the environment. To review the components of this solution, choose each of the three numbered markers.

Marker 1/3

1: Receive traffic

An Amazon API Gateway receives and validates HTTP requests.

Marker 2/3

2: Trigger Lambda function

The API Gateway triggers a Lambda function that sends requests to Amazon DynamoDB.

Marker 3/3

3: Monitor traffic

X-Ray traces requests through API Gateway, Lambda, DynamoDB and back to the client. This helps developers troubleshoot any problems.

Serverless static website with contact form

This serverless setup demonstrates a static website with a contact form hosted on Amazon S3. To review the components of this solution, choose each of the three numbered markers.

Marker 1/3

1: Accept customer input

Customers submit questions using a contact form housed on a static Amazon S3 website.

Marker 2/3

2: Receive request

An API Gateway receives and validates the contact form request.

Marker 3/3

3: Send email

The API Gateway then invokes a Lambda function that sends an email to the business owner using Amazon SES.

Customer support with callback option

This customer support solution provides an alternate channel and callback option so customers can avoid long wait times. To review the components of this solution, choose each of the three numbered markers.

Marker 1/3

1: Initiate contact

A customer calls or texts a customer support center. Calls are placed into the Amazon Connect interactive voice response (IVR) system. Text messages are routed to Amazon Connect from CloudFront.

Marker 2/3

2: Connect to agent

Amazon Connect tries to connect the customer with a live agent.

Marker 3/3

3: Provide options

For calls with long wait lines, customers can choose to receive an agent callback or they can switch to text through a Lambda function.
