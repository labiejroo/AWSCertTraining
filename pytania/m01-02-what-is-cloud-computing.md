## Question 1

You work for a local charity organization. Your organization has sensitive data that must remain within your country for compliance reasons. However, you also need a solution that can scale quickly to handle seasonal spikes in demand. You decide to keep on-premises resources for compliance and use cloud-based resources for dynamic scaling. Which type of cloud deployment does this situation describe?

_Choose 1_

- [ ] A. On-premises deployment
- [ ] B. Public cloud deployment
- [x] C. Hybrid deployment
- [ ] D. Data-compliance deployment

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: With a hybrid cloud solution, you can keep sensitive data on-premises to meet compliance requirements while using cloud-based resources for dynamic scaling.
