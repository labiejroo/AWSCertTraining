## Question 1

You work for a startup company that is developing an application in the cloud. A new security update is available for your operating system (OS), and you are tasked with verifying that the OS is patched accordingly. Which statement BEST describes which party is responsible for applying security patches to the OS that is running in the cloud?

_Choose 1_

- [ ] A. The OS vendor applies the patches.
- [ ] B. AWS is responsible for applying security patches to the OS.
- [x] C. Your company is responsible applying security patches to the OS.
- [ ] D. Both AWS and the customer apply separate patches.

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: The customer is responsible for managing the security configurations and patches for the OS running in the cloud.
