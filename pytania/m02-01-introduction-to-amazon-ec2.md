## Question 1

How does Amazon EC2 compare to running servers on premises?

_Choose 1_

- [ ] A. It is more expensive but offers more control.
- [ ] B. It requires more time to set up and maintain.
- [ ] C. It is only useful for large businesses.
- [x] D. It is more flexible, cost-effective, and quicker to get started.

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Amazon EC2 is designed to be flexible, cost-effective, and quick to set up compared to on-premises servers.

## Question 2

What is multi-tenancy in the context of Amazon EC2 instances?

_Choose 1_

- [x] A. Each virtual machine is isolated but shares resources from a host machine.
- [ ] B. A server can only run one type of application.
- [ ] C. Only one user can use the instance at a time.
- [ ] D. Multiple servers run in the same data center.

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Multi-tenancy allows multiple virtual machines to share resources on the same physical host, with isolation between them.

## Question 3

A company uses Amazon EC2 instances to deploy their application. What would happen if they need to stop or terminate the EC2 instances?

_Choose 1_

- [ ] A. Your instances are permanently deleted and cannot be recovered.
- [ ] B. You are still charged for the instances.
- [ ] C. The instances will automatically restart after a set time.
- [x] D. You pay only for running instances, not for stopped or terminated ones.

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: With Amazon EC2, you only pay for running instances, not for ones that are stopped or terminated.
