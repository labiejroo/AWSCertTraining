## Question 1

What is a primary advantage of using the AWS Command Line Interface (AWS CLI) over the AWS Management Console?

_Choose 1_

- [ ] A. It provides a visual, drag-and-drop interface for managing AWS resources.
- [ ] B. It is only available for Windows users.
- [ ] C. It requires fewer configurations and is ideal for one-time manual provisioning.
- [x] D. It uses automation and scripting, which reduces manual steps and errors.

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: The AWS CLI enables automation through scripting, which is more efficient and reduces manual errors compared to the console.

## Question 2

What is the customer's responsibility when using compute services like Amazon EC2 according to the AWS shared responsibility model?

_Choose 1_

- [ ] A. AWS is responsible for managing the operating system, networking, and applications on the customer's EC2 instances.
- [ ] B. The customer is responsible for securing the physical hardware of their EC2 instances.
- [ ] C. AWS manages the security of the cloud, and the customer manages the security of the infrastructure.
- [x] D. The customer is responsible for configuring, securing, and managing the operating system, networking, and applications on their EC2 instances.

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: The customer handles the operating system, networking, and applications on the EC2 instances. AWS manages the hardware.
