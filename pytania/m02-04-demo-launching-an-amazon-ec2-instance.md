## Question 1

What are the required configurations when launching an Amazon EC2 instance for a web server? (Select THREE.)

_Choose 3_

- [x] A. Amazon Machine Image (AMI)
- [ ] B. Load balancing
- [x] C. Instance type
- [ ] D. Permissions
- [x] E. Storage
- [ ] F. Instance termination behavior

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: To launch an EC2 instance for a web server, configure the AMI to define the operating system and software; select the instance type to allocate CPU, memory, and storage; and set up storage options, including the type and size of the volume.Load balancing, permissions, and instance termination behavior are not required when launching a basic Amazon EC2 web server.

## Question 2

What is an Amazon Machine Image (AMI) used for when launching an Amazon EC2 instance?

_Choose 1_

- [ ] A. To choose the instance size
- [x] B. To pre-configure the operating system and software
- [ ] C. To store instance data
- [ ] D. To configure networking settings

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: An AMI is a pre-configured virtual machine image that contains the operating system, application server, and applications. This helps to launch EC2 instances quickly with the desired software and settings.
