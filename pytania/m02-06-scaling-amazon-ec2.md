## Question 1

What is the primary benefit of scalability and elasticity in AWS?

_Choose 1_

- [ ] A. The ability to permanently increase resource capacity for long-term growth
- [ ] B. The ability to manually adjust resources based on peak usage
- [x] C. The ability to grow and shrink resources dynamically based on real-time demand
- [ ] D. The ability to create fixed resources that never change in size

> Correct! Rationale: By using scalability and elasticity, businesses can adjust resources as needed for optimal performance and cost-efficiency.

## Question 2

What is the main reason for deploying Amazon EC2 instances across multiple Availability Zones?

_Choose 1_

- [x] A. To provide high availability by allowing instances in different Availability Zones to handle traffic if one Availability Zone fails
- [ ] B. To automatically scale instances based on resource usage in each Availability Zone
- [ ] C. To increase the power and speed of each individual instance
- [ ] D. To decrease the cost of instances by distributing them evenly across AWS Regions

> Correct! Rationale: By deploying instances across multiple Availability Zones, businesses can avoid service disruption in the event of an Availability Zone failure.

## Question 3

How does AWS make sure that a business can meet fluctuating demand without over-provisioning resources?

_Choose 1_

- [ ] A. By providing fixed resources that are always available
- [ ] B. By offering resources that are always running, regardless of demand
- [ ] C. By requiring businesses to purchase excess resources in advance to handle peak demand
- [x] D. By allowing businesses to provision resources that automatically scale based on demand

> Correct! Rationale: The AWS scalability and elasticity features automatically adjust resources to meet demand, resulting cost-efficiency and performance.
