## Question 1

A developer just finished building an application that runs flawlessly on their laptop. However, when their team tries to deploy it in a different environment, it crashes because of missing dependencies and configuration mismatches. How do containers help solve this problem?

_Choose 1_

- [ ] A. By providing access to multiple operating systems for compatibility testing
- [ ] B. By automatically scaling the application across multiple cloud providers
- [x] C. By packaging the application and everything it needs to run into one consistent environment
- [ ] D. By eliminating the need to write configuration files

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Containers bundle the application with all of its dependencies and configuration, so it runs the same across different environments.
