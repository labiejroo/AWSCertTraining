## Question 1

A rapidly growing tech startup company is planning to launch a new web application that will require a complex infrastructure setup, including multiple Amazon EC2 instances, Elastic Load Balancing, and Auto Scaling groups. The application must be deployed consistently across different environments. Would AWS CloudFormation be a good solution for managing the company's infrastructure?

_Choose 1_

- [ ] A. CloudFormation should be used only for setting up static websites, not for complex applications.
- [ ] B. CloudFormation is too complicated and would slow down the deployment process.
- [x] C. CloudFormation would be ideal because it supports infrastructure as code (IaC), enabling consistent, repeatable deployments across different environments.
- [ ] D. CloudFormation would not be useful in this scenario because it only supports simple infrastructure setups.

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: CloudFormation is designed to handle complex infrastructure setups. It defines infrastructure as code to help make sure that deployments are consistent across different environments such as development, testing, and production.
