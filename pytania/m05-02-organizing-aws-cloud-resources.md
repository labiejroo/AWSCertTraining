## Question 1

A company is setting up their Amazon VPC. They need to connect their corporate data center through the internet with a secure connection. They also want to make sure the resources are isolated from the public. Which solution would BEST meet their needs?

_Choose 1_

- [x] A. A virtual private gateway with a VPN connection and a private subnet in the Amazon VPC
- [ ] B. An internet gateway with an Amazon VPC and a public subnet
- [ ] C. An internet gateway with a public subnet holding the resources in the Amazon VPC
- [ ] D. An internet gateway with an Amazon VPC and no subnets

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: A virtual private gateway with a VPN connection would work. And using a private subnet is exactly what they need!
