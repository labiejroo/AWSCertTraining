## Question 1

A company is conducting a large-scale migration of their on-premises data center with their data warehouse and data backup. They need a solution that will meet the large amount of bandwidth requirements during migration. The solution will also be used for their ongoing data transfers after the move because they will retain part of their on-premises data center for a hybrid cloud solution.Which AWS solution would best meet their needs?

_Choose 1_

- [x] A. AWS Direct Connect link to their on-premises network and the AWS Cloud
- [ ] B. AWS Site-to-Site VPN
- [ ] C. AWS Client VPN
- [ ] D. AWS Private Link to their on-premises datacenter

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Direct Connect would provide the bandwidth requirements for the migration, in addition to the ongoing data transfers in their hybrid solution.

## Question 2

A company is choosing the type of gateway for their network. They need to connect their corporate data center with their private subnet in their Amazon Virtual Private Cloud. Their gateway needs to allow only protected internet traffic to enter into the Amazon VPC. It should also allow a connection between their Amazon VPC and a private network only if it is coming from an approved network.Which type of gateway would BEST meet their needs?

_Choose 1_

- [x] A. Virtual private gateway
- [ ] B. Amazon API Gateway
- [ ] C. AWS Transit Gateway
- [ ] D. Internet gateway

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: A virtual private gateway is the component that allows protected internet traffic to enter into the VPC. This is perfect because it will restrict access to only protected internet traffic.
