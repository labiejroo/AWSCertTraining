## Question 1

An enterprise customer with a worldwide sales force is looking to deliver their large library of sales training content. They want to make sure their sales force can access the media-rich training content with low latency and reduced costs.Which AWS service would BEST fit the customer's need?

_Choose 1_

- [x] A. Amazon CloudFront
- [ ] B. AWS Global Accelerator
- [ ] C. Amazon Route 53
- [ ] D. Amazon VPC

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: CloudFront is a service that uses the AWS global network to improve application availability, performance, and security.

## Question 2

After years of working with different domain registration companies, a media company is looking for a solution to manage all their existing domain names. They also want to register new domain names. Ideally, they would like to manage all their domain names in a single service.Which AWS service would BEST fit the customer's need?

_Choose 1_

- [ ] A. Amazon VPC
- [x] B. Amazon Route 53
- [ ] C. Amazon CloudFront
- [ ] D. AWS Global Accelerator

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Amazon Route 53 is a highly available and scalable cloud DNS service. It will makes it possible for the customer to manage all their domains in a single service.
