## Question 1

AnyCompany Media wants to migrate its file shares to AWS while maintaining compatibility with existing applications. They need a solution that supports Server Message Block (SMB) protocol and integrates with Microsoft Active Directory.Which AWS service should they implement in this scenario?

_Choose 1_

- [ ] A. Amazon Elastic Block Store (Amazon EBS)
- [ ] B. Amazon Elastic File System (Amazon EFS)
- [ ] C. Amazon S3 File Gateway
- [x] D. Amazon FSx for Windows File Server

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: FSx for Windows File Server is a fully managed Windows file system. It supports SMB protocol, integrates with Active Directory, and provides the Windows compatibility needed for this scenario.
