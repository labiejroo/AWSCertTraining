## Question 1

A staffing resource company is building an application that must store employee information with unpredictable traffic patterns. Their application requires consistent performance at all times, and the development team wants to focus on features rather than database management tasks.Which Amazon DynamoDB capability BEST addresses the needs for this workload?

_Choose 1_

- [x] A. Auto scaling with provisioned capacity
- [ ] B. Predefined schema enforcement
- [ ] C. Manual configuration of read/write capacity units
- [ ] D. Fixed storage limit allocation

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Auto scaling with provisioned capacity means that DynamoDB can automatically adjust capacity in response to actual traffic patterns. This keeps application performance consistent during unpredictable peaks in traffic, while optimizing costs during slower periods.
