## Question 1

The owner of a car dealership wants to determine why her service department has lost business over the past year. She wants to analyze a large number of documented customer comments to better understand customer sentiment. Which AWS service would work well for this use case?

_Choose 1_

- [ ] A. Amazon Translate
- [ ] B. Amazon Textract
- [ ] C. Amazon Personalize
- [x] D. Amazon Comprehend

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Amazon Comprehend can extract key insights, such as customer sentiment, from documents. This can help the owner better understand her customers.

## Question 3

An instructional designer is developing a new course on customer service skills. He wants to include several simulated calls to reinforce the learning. Because he doesn't have access to a recording studio, he needs a quick way to convert his scripts to speech. Which service would work well for this use case?

_Choose 1_

- [ ] A. Amazon Textract
- [ ] B. Amazon Kendra
- [ ] C. Amazon Translate
- [x] D. Amazon Polly

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Amazon Polly converts text into lifelike speech. It supports multiple languages, different genders, and a variety of accents. It is an ideal match for this use case.

## Question 5

A team of machine learning (ML) engineers is developing a new ML model for a highly specialized application. They need complete control over the ML training process. So, they are developing their own custom solution using the PyTorch ML framework. What is an ML framework?

_Choose 1_

- [x] A. A software library with pre-built, optimized components
- [ ] B. A managed service pre-trained to perform specific functions
- [ ] C. An integrated development environment (IDE) that provides simplified access to the company's ML projects
- [ ] D. An Amazon EC2 instance that is optimized for ML training

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: An ML framework is a software library or tool that provides experienced ML practitioners with pre-built, optimized components for building machine learning models.
