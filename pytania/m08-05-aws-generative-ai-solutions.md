## Question 1

A large advertising agency wants to quickly integrate a new content generation feature into its existing enterprise-wide design application. The new feature needs to be able to generate both text and images. The agency doesn't want to manage any new infrastructure. Which service would work best for this use case?

_Choose 1_

- [x] A. Amazon Bedrock
- [ ] B. Amazon SageMaker JumpStart
- [ ] C. Amazon Q Developer
- [ ] D. Amazon Q Business

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Amazon Bedrock would work well for fully managed, enterprise-grade, multimodal generative AI.

## Question 2

A software development company is working on a new product with a very tight deadline. The company needs a way to develop code faster without sacrificing reliability or security. Which service could best help this company meet its deadline?

_Choose 1_

- [ ] A. Amazon Bedrock
- [ ] B. Amazon SageMaker JumpStart
- [x] C. Amazon Q Developer
- [ ] D. Amazon Q Business

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Amazon Q Developer provides code recommendations to accelerate development of C#, Java, JavaScript, Python, and TypeScript applications. It's a good fit for this use case.
