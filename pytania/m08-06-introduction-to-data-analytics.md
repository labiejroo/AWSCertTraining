## Question 1

Data pipelines are automated assembly lines used to make the ETL process efficient and repeatable. What does ETL stand for?

_Choose 1_

- [x] A. Extract, transform, load
- [ ] B. Export, translate, link
- [ ] C. Evaluate, test, launch
- [ ] D. Explore, transfer, log

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: In data analytics, ETL stands for extract, transform, load. Sometimes, an ELT process is followed in which the transform step is last.

## Question 2

In the field of data analytics, analysts transform raw historical data into something useful. What are these analysts working to uncover with this transformed data?

_Choose 1_

- [x] A. Valuable insights and trends
- [ ] B. Hardware malfunctions
- [ ] C. Programming errors and bugs
- [ ] D. Personal customer information

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: In the field of data analytics, analysts transform raw historical data into valuable insights and trends.
