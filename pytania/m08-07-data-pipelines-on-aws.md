## Question 1

A data analytics team is creating an automated data pipeline on AWS.Which AWS services could they choose for data ingestion? (Select TWO.)

_Choose 2_

- [ ] A. Amazon Redshift
- [x] B. Amazon Kinesis Data Streams
- [ ] C. Amazon EMR
- [ ] D. AWS Glue Data Catalog
- [x] E. Amazon Data Firehose

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Amazon Kinesis Data Streams can be used to ingest real-time data, and Amazon Data Firehose can be used to ingest near real-time data.

## Question 2

The data analytics team must ingest vast amounts of unstructured data into its pipeline. Which AWS service is the BEST choice for storing this data?

_Choose 1_

- [ ] A. Amazon Athena
- [x] B. Amazon S3
- [ ] C. Amazon Data Firehose
- [ ] D. Amazon Redshift

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Amazon S3 can store virtually unlimited amounts of unstructured data. This makes it a popular data lake choice and the best storage option for the team.

## Question 3

Which AWS service is BEST suited for data processing in a data pipeline?

_Choose 1_

- [ ] A. Amazon QuickSight
- [ ] B. Amazon S3
- [x] C. AWS Glue
- [ ] D. Amazon Data Firehose

<!-- klucz: znaczniki przy odpowiedziach -->
