## Question 1

Which processes involve locking and unlocking data with a special key so only authorized users can access it?

_Choose 1_

- [ ] A. Tokenization and masking
- [ ] B. Authentication and authorization
- [x] C. Encryption and decryption
- [ ] D. Hashing and salting

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: These processes specifically involve locking (encryption) and unlocking (decryption) data with a special key to make sure only authorized users can access it.

## Question 2

A tax preparation company needs to secure sensitive customer data moving from its database to its web application on AWS. Which of these services can help them secure the data in transit?

_Choose 1_

- [ ] A. Amazon Macie
- [x] B. AWS Certificate Manager (ACM)
- [ ] C. Amazon DynamoDB
- [ ] D. Amazon S3

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: ACM centralizes the management of SSL/TLS certificates that provide data encryption in transit.
