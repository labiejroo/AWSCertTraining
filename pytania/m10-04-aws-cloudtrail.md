## Question 1

A company wants to store the files that contain API activities for an AWS account in an Amazon S3 bucket. They want to retain these files for auditing and compliance.Which solution and feature would provide this capability?

_Choose 1_

- [x] A. AWS CloudTrail logs
- [ ] B. Amazon CloudWatch Logs
- [ ] C. AWS CloudTrail events
- [ ] D. AWS CloudTrail Insights

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: CloudTrail logs can be delivered to an S3 bucket or Amazon CloudWatch logs and are not limited to 90 days.
