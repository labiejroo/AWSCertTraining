## Question 1

An enterprise customer with a large team of developers needs a way to ensure specific configuration guidelines for the developers when creating AWS resources. They want to assess and audit the AWS resources to make sure that the team is using the most cost-effective approved list of Amazon EC2 instances.Which AWS service would best fit the customer's need?

_Choose 1_

- [x] A. AWS Config
- [ ] B. AWS Audit Manager
- [ ] C. AWS Artifact
- [ ] D. AWS CloudTrail

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: AWS Config is the best choice because it will assess, audit, and evaluate the configurations of the developer's AWS resources.
