## Question 1

A customer is getting started on their migration and is not sure how to build a business case to justify their move.Which solution would BEST meet the requirements?

_Choose 1_

- [x] A. Migration Evaluator
- [ ] B. AWS Application Discovery Service
- [ ] C. AWS Application Migration Service
- [ ] D. AWS Migration Hub

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Migration Evaluator is a migration assessment service that helps create a business case for AWS Cloud planning and migration.

## Question 2

A customer is looking for a tool to help centralize the view of all their migration tasks and help track their migration.Which solution would BEST meet the requirements?

_Choose 1_

- [ ] A. AWS Application Discovery Service
- [ ] B. Migration Evaluator
- [x] C. AWS Migration Hub
- [ ] D. AWS Application Migration Service

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Migration Hub is a centralized hub to take the customer through the discovery, assessment, planning, and execution phases of their migration.
