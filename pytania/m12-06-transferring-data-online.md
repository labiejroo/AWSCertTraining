## Question 1

A healthcare company is migrating large amounts of data between their on-premises storage in Amazon S3. They want to automate the process and be able to schedule the migration to off-peak times and be able to check on progress and task reporting.Which service would best meet their need to transfer the data?

_Choose 1_

- [ ] A. AWS Direct Connect
- [ ] B. Transfer using the internet, no AWS service needed
- [ ] C. AWS Transfer Family
- [x] D. AWS DataSync

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: DataSync streamlines and accelerate secure data migrations. It manages data movement workloads with bandwidth throttling, migration scheduling, task filtering, and task reporting.
