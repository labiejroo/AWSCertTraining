## Question 2

What is the primary function of the AWS Cloud Adoption Framework (AWS CAF)?

_Choose 1_

- [x] A. It provides tools to help accelerate the migration journey, organize resources, and align management during the transition.
- [ ] B. It acts as a centralized hub to manage a company's migration to the AWS Cloud.
- [ ] C. It migrates on-premises databases and data to the AWS Cloud.
- [ ] D. It is also known as the seven Rs or the seven migration strategies.

## Question 7

During their upcoming migration, the database administrator would like to move from their current database to an AWS managed database to offload some of the database administration. They would also like to use a tool to plan, assess, convert, and migrate the database.Which migration solution would BEST meet their needs?

_Choose 1_

- [ ] A. AWS Migration Hub
- [ ] B. AWS Schema Conversion Tool (AWS SCT)

## Question 8

A credit card company is migrating large amounts of sensitive data from their on-premises storage to the AWS Cloud. They want to automate the process and schedule the migration during off peak times. They also want to be able to check on progress and task reporting. They do not have a dedicated private connection between their data center and the AWS Cloud.Which online migration solution would meet their needs?

_Choose 1_

- [ ] A. AWS Transfer Family
- [x] B. AWS DataSync
- [ ] C. AWS Snowball Edge Storage Optimized Devices
- [ ] D. Virtual private gateway

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: DataSync is an online migration service specifically designed for automating and accelerating data transfer. DataSync streamlines and accelerates moving large amounts of data between on-premises storage and AWS storage services like Amazon S3, Amazon Elastic File System (Amazon EFS), and Amazon FSx for Windows File Server.

## Question 9

An engineering company is migrating large amounts of proprietary intellectual property design files from their on-premises data center to the AWS Cloud. _Choose 1_

- [ ] A. AWS DataSync
- [ ] B. AWS Direct Connect
- [ ] C. AWS Snowball Edge Storage Optimized Devices
- [x] D. AWS Transfer Family

> Correct! Rationale: Transfer Family makes it possible to seamlessly manage and share data with secure, and scalable file transfers.
