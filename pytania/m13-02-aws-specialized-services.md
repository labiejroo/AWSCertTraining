## Question 1

A development team for a small marketing company needs a debugging and performance analysis tool to visualize their online application’s behavior. The application is hosted on AWS.Which AWS service should this team choose?

_Choose 1_

- [x] A. AWS X-Ray
- [ ] B. AWS CodePipeline
- [ ] C. AWS Amplify
- [ ] D. AWS AppSync

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: X-Ray provides visualization tools specifically designed for debugging and performance analysis of applications.

## Question 2

A large automotive company wants to use the power of AI in its customer service center. They need a solution that includes call routing, recording, and analytics.Which AWS service can provide these capabilities?

_Choose 1_

- [x] A. Amazon Connect
- [ ] B. Amazon WorkSpaces
- [ ] C. AWS Amplify
- [ ] D. Amazon Simple Email Service (Amazon SES)

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Amazon Connect is an AI-powered contact center solution that offers call routing, recording, and analytics capabilities.

## Question 3

An IT department needs to provide employees access to several software-as-a-service (SaaS) online applications.Which AWS service can provide this access?

_Choose 1_

- [ ] A. AWS AppSync
- [ ] B. AWS IoT Core
- [x] C. Amazon AppStream 2.0
- [ ] D. Amazon Connect

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: AppStream 2.0 delivers desktop applications to users through web browsers, enabling secure SaaS application access for employees.

## Question 4

Which options are Internet of Things (IoT) solutions? (Select TWO.)

_Choose 2_

- [ ] A. A mobile app to order food from a favorite restaurant
- [x] B. A wearable device that tracks steps per day on a smartphone
- [ ] C. A smart TV that recommends shows based on viewing history
- [x] D. A Wi-Fi enabled plug that can be used to turn off lights remotely
- [ ] E. An online banking application used to check account balances

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: The wearable device that tracks steps on a smartphone and the Wi-Fi enabled plug that can be used to turn off lights remotely are both examples of IoT solutions. Although these other options are digital solutions, they do not involve physical devices that communicate with networked applications.
