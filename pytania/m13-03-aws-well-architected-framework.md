## Question 1

A development team is releasing frequent updates to an application hosted on AWS. Right now, each deployment requires manual steps that often result in downtime or inconsistent environments.What AWS practice from the Well-Architected Framework could help in this situation?

_Choose 1_

- [ ] A. Focus on securing their deployments (Security).
- [x] B. Automate deployments through a continuous integration and continuous delivery pipeline (Operational Excellence).
- [ ] C. Reduce the cost of the infrastructure used for deployments (Cost Optimization).
- [ ] D. Use AWS resources more effectively during deployment (Performance Efficiency).

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: Automating deployments with a CI/CD pipeline like AWS CodePipeline would streamline the process, reduce downtime, and help provide more reliable deployments.

## Question 2

What is the purpose of the AWS Well-Architected Tool (AWS WA Tool)?

_Choose 1_

- [ ] A. To automate cost forecasting for cloud projects
- [ ] B. To manage user permissions across AWS services
- [x] C. To assess and improve cloud workloads based on six key architectural pillars
- [ ] D. To migrate workloads between AWS Regions

<!-- klucz: znaczniki przy odpowiedziach -->

> Correct! Rationale: The AWS WA Tool helps evaluate workloads using the six pillars: Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, and Sustainability.
