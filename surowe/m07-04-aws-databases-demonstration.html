AWS Databases Demonstration

AWS Databases Demonstration

In this lesson, you will learn how to do the following:

  • Create an Amazon RDS database instance by using the AWS Management Console.
  • Query an Amazon RDS for MySQL database to create a table with values.
  • Create a DynamoDB table and add items to it by using the console.
  • Scan a DynamoDB table by using the console.

This demonstration offers a hands-on exploration of the fundamental features of Amazon RDS and DynamoDB through the AWS Management Console. You will be guided through the process of creating a new Amazon RDS instance from the console and querying it by using SQL to create entries. You will then see how to create and configure a DynamoDB table by using the console. In this lesson, you will learn the core functionality of two primary AWS database services.
