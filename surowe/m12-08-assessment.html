Knowledge Check

Question -

The migration team wants to make sure the organization considers a company-wide change management strategy for successful cloud adoption. Which Cloud Adoption Framework (CAF) perspective would they use?

Choose 1.
A. Operations
B. Business
C. People
D. Security
Correct!
Rationale: The People perspective supports development of an organization-wide change management strategy for successful cloud adoption.

Knowledge Check

Question -

What is the primary function of the AWS Cloud Adoption Framework (AWS CAF)?

Choose 1.
A. It provides tools to help accelerate the migration journey, organize resources, and align management during the transition.
B. It acts as a centralized hub to manage a company's migration to the AWS Cloud.
C. It migrates on-premises databases and data to the AWS Cloud.
D. It is also known as the seven Rs or the seven migration strategies.
Correct!
Rationale: AWS CAF provides AWS experience and best practices to companies preparing to migrate to the AWS Cloud. The framework also provides tools to help accelerate the migration journey, organize resources, and align management during the transition.

Knowledge Check

Question -

What are the seven migration strategies that are commonly used when customers migrate to the AWS Cloud?

Choose 1.
A. There are not seven, there are three (Assess, Mobilize, and Migrate and Modernize)
B. Relocate, Remediate, Retrofit, Refactor, Regrade, Retool, Remove
C. Business, People, Governance, Platform, Security, Operations, IT
D. Relocate, Rehost, Replatform, Refactor, Repurchase, Retain, and Retire
Correct!
Rationale: The seven Rs, or migration strategies, are Relocate, Rehost, Replatform, Refactor, Repurchase, Retain, and Retire.

Question -

Choose 1.
A. Migration Evaluator
B. AWS Application Migration Service
C. AWS Application Discovery Service

Correct!

Knowledge Check

Question -

During their upcoming migration, the database administrator would like to move from their current database to an AWS managed database to offload some of the database administration. They would also like to use a tool to plan, assess, convert, and migrate the database.Which migration solution would BEST meet their needs?

Choose 1.
A. AWS Migration Hub
B. AWS Schema Conversion Tool (AWS SCT)
C. AWS Database Migration Service (AWS DMS)
D. Migration Evaluator
Correct!
Rationale: Database Migration Service makes it possible to quickly and securely migrate databases and data replication to the AWS Cloud. It provides a way to plan, assess, convert, and migrate databases even with data warehouses in one central tool and can be used when converting databases.

Knowledge Check

Question -

A credit card company is migrating large amounts of sensitive data from their on-premises storage to the AWS Cloud. They want to automate the process and schedule the migration during off peak times. They also want to be able to check on progress and task reporting. They do not have a dedicated private connection between their data center and the AWS Cloud.Which online migration solution would meet their needs?

Choose 1.
A. AWS Transfer Family
B. AWS DataSync
C. AWS Snowball Edge Storage Optimized Devices
D. Virtual private gateway
Correct!
Rationale: DataSync is an online migration service specifically designed for automating and accelerating data transfer. DataSync streamlines and accelerates moving large amounts of data between on-premises storage and AWS storage services like Amazon S3, Amazon Elastic File System (Amazon EFS), and Amazon FSx for Windows File Server.

Question -

An engineering company is migrating large amounts of proprietary intellectual property design files from their on-premises data center to the AWS Cloud. They want a service that has fully managed support for secure file transfers with several different protocols, like Secure File Transfer Protocol (SFTP) and File Transfer Protocol Secure (FTPS)Which online migration solution would meet their needs?

Choose 1.
A. AWS DataSync
B. AWS Direct Connect
C. AWS Snowball Edge Storage Optimized Devices
D. AWS Transfer Family
Correct!
Rationale: Transfer Family makes it possible to seamlessly manage and share data with secure, and scalable file transfers. This service provides fully managed support for secure file transfers over SFTP (Secure File Transfer Protocol), FTPS (File Transfer Protocol Secure), FTP (File Transfer Protocol) and others.
